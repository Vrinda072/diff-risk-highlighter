Self-trigger regression check

Loads the real src/risk-engine.js + src/content.js (not copies) against a small synthetic diff at a URL path matching /pull/<n>/files, so the content script's own page-detection gate passes and it runs for real. Regression this guards against: a bug where the extension's own DOM writes (badges, the summary bar) retriggered its own MutationObserver, running the scan forever even on an idle page — found by instrumenting a live GitHub PR and watching the scan counter climb with zero user interaction. Fixed by disconnecting the observer for the duration of the script's own synchronous writes.
